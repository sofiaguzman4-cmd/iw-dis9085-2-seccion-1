# bitácora solemne-02
### ¿Qué hice en el sitio?

Trabajé en el HTML de la página y arreglé el kit UI de Figma, intentando ordenar los elementos y dejar los estilos más claros. También estuve viendo el tema de la tipografía y arreglando algunas cosas de los botones del carrusel.

### ¿Qué dificultades tuve?

Me costó un poco hacer el kit UI y ordenar todo para que se viera coherente. También hay algunos textos que no quieren tomar la tipografía que corresponde :') Estuve haciendo cambios en el código para ver si se solucionaba.

### ¿Qué aprendí?

Aprendí un poco más de HTML  cómo poner tipografías de Google Fonts y cómo ordenar los elementos para armar un kit UI en Figma.

### Uso de IA

Usé IA para ayudarme con la tipografía Intel One Mono en el HTML, específicamente para ver dónde tenía que vincularla y cómo hacer que se aplicara a los textos de la página. :)
